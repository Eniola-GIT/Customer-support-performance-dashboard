# Customer Support Performance & Satisfaction Analysis Dashboard

## Project Overview

This project analyzes customer support ticket data to uncover operational bottlenecks, customer satisfaction trends, and actionable business recommendations.

The goal was not just to build a dashboard but to answer key business questions that management could use to improve customer experience and operational efficiency.

## Business Questions

- How many tickets were received?
- What percentage of tickets were resolved?
- Which ticket types generated the highest demand?
- Which support channels handled the most tickets?
- How satisfied were customers?
- What actions should management take?

---

## Key Findings

- Only 32.7% of tickets were resolved.
- Refund requests and technical issues generated the highest demand.
- Chat support achieved the highest customer satisfaction scores.
- More than 5,700 tickets lacked customer feedback.
- Customer satisfaction averaged 2.99/5.

---

## Recommendations

- Reduce unresolved ticket backlog.
- Improve follow-up processes.
- Standardize customer feedback collection.
- Investigate refund request bottlenecks.
- Expand successful support-channel practices.
